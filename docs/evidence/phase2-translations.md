# Translation coverage

Business dictionaries: 170 keys per language (English, Malay, Arabic), with equal-key/nonempty-value assertions. Static business, services and pilot page data-i18n keys are covered. Runtime tests verify static and dynamic form data survives an Arabic RTL switch.

This is dictionary coverage, not whole-product completeness. Account, Owner HQ, existing safety/Family Link flows, raw server errors, composite history strings and all generated status bindings remain PARTIAL. Human mobile/RTL visual review is BLOCKED locally by denied Chromium sockets. Provider-entered content is intentionally unchanged.
